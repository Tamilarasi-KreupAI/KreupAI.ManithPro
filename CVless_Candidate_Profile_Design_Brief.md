# DESIGN BRIEF: CV-less Candidate Profile Dashboard

### Recruitment Platform -- Apple-like, Dashboard-based, Editable, AI-enhanced

## 1. Project Overview

### Objective

Design a CV-less Candidate Profile Dashboard that replaces traditional
PDF résumés with a stunning, interactive, structured, and auto-saving
user interface. The experience must: - Provide an Apple-like polished
feel - Allow direct inline editing (Notion-like) - Present candidate
information in a dashboard format optimized for recruiters - Support
AI-assisted profile population and enhancement - Provide recruiters and
hiring managers with scannable, consistent, and actionable information

This dashboard becomes the candidate's identity within the ecosystem ---
replacing CVs entirely.

## 2. Primary Users & Their Needs

### 1. Candidates

-   Create and maintain a professional profile easily
-   Direct inline editing
-   Auto-save for every change
-   AI suggestions for bullets, summaries, achievements
-   Clean attachment & portfolio support
-   Beautiful presentation

### 2. Recruiters & Hiring Managers

-   Fast scanning (10--30 seconds)
-   Predictable structure across all profiles
-   High-value info surfaced first
-   Tools for tagging, notes, evaluations
-   Shareable profile links without downloads

## 3. Experience Vision

A blend of: - Apple dashboard aesthetics - Notion-style inline editing -
GitBook-like structure and navigation

## 4. Design Principles

1.  Polished like Apple\
2.  Structured like a dashboard\
3.  Editable like Notion\
4.  Scannable like ATS\
5.  Zero clutter, no PDFs
